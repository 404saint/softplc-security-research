# Part I: Software PLC Foundations

> Understanding the architecture, deployment, execution, and security boundaries of software-based PLCs.

## Overview

This part establishes the technical foundation for understanding Software PLCs as complete industrial control environments. It explores how they are built, where they operate, how control applications are developed and executed, and how their architecture shapes the security boundaries around them.

## Research Scope

The investigation covers six areas:

- Physical PLCs vs Software PLCs
- Software PLC Deployment Models
- Industrial Control Logic and Programming Languages
- PLC Program Execution
- PLC Engineering and Program Lifecycle
- Software PLC Security Boundaries

OpenPLC Runtime v4 is used as a practical reference where relevant, alongside industrial standards, technical documentation, academic publications, and other credible sources.

## Research Approach

The research combines technical documentation, standards, academic publications, and selective practical validation.

Findings are distinguished between documented behavior, direct lab observations, and technical interpretation. Lab experiments are conducted where they provide meaningful evidence rather than simply to demonstrate a concept.

## Disclaimer

This repository is intended for educational and defensive security research. Practical experiments should be conducted only in authorized, isolated environments.

Technical findings are subject to the documented versions, configurations, and conditions under which they were established. They should not be treated as universal characteristics of all software PLC implementations.
